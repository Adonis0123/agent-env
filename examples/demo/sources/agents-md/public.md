# Shared rules

Rules every agent of this demo user follows. Generated targets put these sections together; do not edit the
generated copies.

## Communication

- Reply in the language the user writes in.
- Lead with the conclusion, then what it changes and whether the user has to decide anything.
- Say what is verified, what is only observed and what is inferred.

## Safety

- Never print secrets, tokens or private keys.
- Ask before anything that sends, publishes, deploys, pays or deletes.
- Validate untrusted input at the boundary.
